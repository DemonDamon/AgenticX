## 2. 关键设计决策（本子规划内定）

| # | 决策 | 理由 |
|---|---|---|
| D1 | **两个根地址**：`control_base`（控制面）与 `runtime_base`（会话面），缺省都取 `base_url`；最终请求 URL = `<control_base>/ma/v1/agents…`、`<runtime_base>/ma/v1/sessions…`。生产只配 `base_url`（nginx 入口）；本地开发配 `control_base=http://127.0.0.1:3001/api`、`runtime_base=http://127.0.0.1:8092` | nginx 路径重写只在生产存在；本地没有 nginx |
| D2 | **apply 文件格式**（YAML，顶层键固定，未知键拒绝）：`kind: agent`、`slug`、`display_name`、`description?`、`runtime?`（`cloud`/`desktop_worker`，缺省 `cloud`）、`assignment_keys?`（缺省 `["all"]`）、`worker_keys?`（缺省 `[]`）、`default_environment_id?`、`manifest`（对象）、`note?` | 与 POST /agents 的键一一对应；`kind` 预留给后续资源 |
| D3 | **apply 语义**：按 `slug` 在 `GET /agents` 结果中查找。不存在 → `POST /agents`（初始版本 1）；存在 → 先 `PATCH` 变化的元数据键（`display_name`、`description`、`runtime`、`assignment_keys`、`worker_keys`、`default_environment_id`），再 `POST /versions`（`expected_latest_version = agent.latest_version`）。`409 agent_version_conflict` 时重新 `GET /agents/:id` 后重试一次。`--publish` → 若 `lifecycle != "published"` 再 `PATCH {lifecycle:"published"}` | 幂等、可重复执行；发布是显式动作 |
| D4 | **apply 输出（逐字，W5 门依赖）**：新建 `created agent <slug> (<id>) version 1`；新版本 `updated agent <slug> (<id>) version <N>`；manifest 未变 `unchanged agent <slug> (<id>) version <N>`；`--publish` 生效时追加一行 `published agent <slug>`。退出码：0 成功；1 接口错误（打印 `error: <code>: <message>` 到 stderr）；2 文件 / 本地校验错误 | 脚本可解析；CI 可判断 |
| D5 | **凭证**：`--token` 或环境变量 `AGX_MA_TOKEN`；必须以 `agx-pat-` 开头。地址：`--base-url` / `AGX_MA_BASE_URL`（缺省 `http://127.0.0.1`），`--control-url` / `AGX_MA_CONTROL_URL`，`--runtime-url` / `AGX_MA_RUNTIME_URL`。**不**写入任何配置文件；token 不出现在输出、异常文本、`repr` | 最小面；避免把 PAT 落盘 |
| D6 | **会话列表接口** `GET /ma/v1/sessions?agent_id=&limit=&scope=`：缺省只返回 `created_by_user_id == principal.user_id` 的会话；`scope=tenant` 需 `ma:admin`（否则 403 `forbidden_scope`）；需 `ma:sessions:read`；`limit` 1–100 缺省 20；按 `created_at` 倒序；响应 `{"data":[session wire]}` | `agx ma sessions` 需要；缺省按本人过滤，对 D01 的设备 PAT 也安全（D01 中间件不匹配该路径） |
| D7 | **事件续流**：客户端记录已产出的最大 `seq`；连接中断（网络错误、服务端关闭、读超时）后以请求头 `Last-Event-ID: <seq>` 重连，最多 `maxReconnects`（缺省 5）次，间隔 `min(1000 * 2^(n-1), 10000)` ms；收到的 `seq <= lastSeq` 帧丢弃；预览帧（无 `id`）只在调用方要求时产出，不推进游标。401 / 403 / 404 不重连，直接抛错 | master §4 决策 6；不丢不重 |
| D8 | **SDK 不做重试与缓存**：除 D7 的流重连外，所有请求失败即抛 `MaApiError`；不自动处理 `requires_action` | 行为可预测 |
| D9 | **Python 侧两份客户端**：框架 `agenticx/managed/api_client.py`（CLI 使用，同步 `httpx.Client`）与 `enterprise/packages/sdk-py` 的 `agenticx_sdk.managed`（独立包，不依赖 `agenticx`）。两者对同一组 HTTP 夹具（`tests/fixtures/managed_agents/client_cases.json`）跑相同断言 | sdk-py 是对外独立包，不能依赖框架；框架 CLI 不能依赖未安装的 sdk-py |

## 4. 数据与协议

### 4.1 `GET /ma/v1/sessions`（agent-runtime / `agx ma serve`）

| 参数 | 规则 |
|---|---|
| `agent_id` | 可选；非空时按 Agent 过滤 |
| `limit` | 可选整数 1–100，缺省 20；非整数 → 400 `invalid_request` |
| `scope` | 可选 `mine`（缺省）或 `tenant`；`tenant` 需 `ma:admin`，否则 403 `forbidden_scope`（`details: {"scope": "ma:admin"}`）；其他值 → 400 |

响应 200：`{"data": [<session_to_wire(record)>...]}`。需要 `ma:sessions:read`。

### 4.2 apply 文件（`examples/managed/agent.apply.yaml`，逐字）

本地校验（exit 2，错误逐行打印到 stderr）：文件不可读 / YAML 解析失败 → `error: <path>: cannot read`；顶层不是映射 → `error: apply file must be a mapping`；未知键 → `error: unknown key "<k>"`；`kind != "agent"` → `error: kind must be "agent"`；`slug` 不符 `^[a-z0-9][a-z0-9-]{1,62}$` → `error: slug is invalid`（与 `enterprise/packages/iam-core/src/repos/agents.ts:129` 的 `SLUG_RE` 逐字一致）；`display_name` 为空 → `error: display_name is required`；`validate_manifest(manifest).ok is False` → 每条 `errors` 原样打印（已是 `manifest.<path>: <message>` 格式）。

### 4.3 SSE 解析规则（TS 与 Python 一致，同 `agenticx/managed/sse.py::aiter_sse` 文档）

按行切分（去掉行尾 `\r`）；空行分发一帧（至少有一行 `data:` 才分发）；`:` 开头为注释；字段名与值以第一个 `:` 分隔，值去掉**一个**前导空格；多行 `data` 以 `\n` 连接；`event` 缺省 `message`；`id` 只属于当前帧。持久事件帧必有 `id`（= `seq` 的十进制）且 `data` JSON 含数字 `seq`；预览帧无 `id`。

URL 与请求：
- `control = trimSlash(controlBaseUrl ?? baseUrl) + "/ma/v1"`；`runtime = trimSlash(runtimeBaseUrl ?? baseUrl) + "/ma/v1"`。
- agents / versions / environments → `control`；sessions / events → `runtime`。路径参数一律 `encodeURIComponent`。
- 头：`authorization: Bearer <token>`；有 body 时 `content-type: application/json`；`events.stream` 加 `accept: text/event-stream`。
- 非 2xx：尝试解析 `{"error":{code,message,details}}` → `MaApiError(status, code, message, details)`；解析失败 → `MaApiError(status, "http_error", \`HTTP ${status}\`)`；`fetch` 抛错 → `MaApiError(0, "network_error", String(err))`（消息里不得出现 token）。
- `versions.list` 映射 `next_before_version → nextBeforeVersion`；`events.list` 映射 `has_more / next_after_seq`。
- 构造时 `token` 不以 `agx-pat-` 开头 → `throw new MaApiError(0, "invalid_token", "token must be an agx-pat- personal access token")`。

`events.stream` 算法：

```text
lastSeq = opts.afterSeq ?? 0; reconnects = 0
loop:
  headers = base headers + (lastSeq > 0 ? { "last-event-id": String(lastSeq) } : {})
  url = `${runtime}/sessions/${id}/events/stream` + (includePreviews ? "?event_deltas[]=agent.message" : "")
  try res = await fetch(url, { headers, signal })
  catch -> if signal aborted: return; else goto retry
  if res.status in (401, 403, 404) or (res.status >= 400 and res.status < 500): throw MaApiError(...)   # no reconnect
  if !res.ok or !res.body: goto retry
  for await frame of parseSse(res.body):
    data = JSON.parse(frame.data) (skip on failure)
    if frame.id === null: if includePreviews: yield {kind:"preview", frame: data}; continue
    seq = Number(frame.id); if !Number.isInteger(seq) or seq <= lastSeq: continue
    lastSeq = seq; reconnects = 0
    yield {kind:"event", event: data}
    if untilIdle and data.type in ("session.status_idle", "session.status_terminated"): return
  # stream ended without untilIdle stop -> reconnect
retry:
  if ++reconnects > maxReconnects: throw MaApiError(0, "stream_disconnected", "event stream disconnected")
  await sleep(min(1000 * 2 ** (reconnects - 1), 10000), signal)
```

client = _client(...)
found = client.find_agent_by_slug(spec.slug)

    if dry_run: echo(f"would create agent {slug}"); return

    created = client.create_agent(body)

    patch = {k: spec[k] for k in PATCHABLE_KEYS if k in spec and spec[k] != agent.get(k)}

## 10. 风险与待确认

1. **按 slug 查找**依赖 `GET /agents` 全量列表；租户 Agent 数量很大时较慢（当前无分页参数）。后续可在控制面加 `?slug=` 过滤（Q1，属 E02 扩展，本文不做）。
2. **apply 不删除远端多余配置**：文件里没写的元数据键（如 `default_environment_id`）保持远端原值，不会被清空；需要清空时显式写 `null`。
3. **两份 Python 客户端**（D9）：靠共享夹具防漂移；若后续 sdk-py 成为框架依赖，再合并（Q2）。
4. **本地开发两个根地址**（D1）：文档与 `--help` 写清 `AGX_MA_CONTROL_URL` 需带 `/api`。
