# bounded-request-diagnostics

Planned-with: gpt-6.1-sol
Suggested-Impl-Model: gpt-6.1-sol

Baseline: 7dc65eb0 (shared byte-active SSE reader and no-replay guards).

## Evidence and scope
The existing `internal/observability/metrics.go::Registry` records first-callback TTFT but cannot separate admission, response headers, the first body byte and the first actual emitted model delta. `internal/metering/trace_reporter.go` already persists bounded trace metadata through `internal/server/cache_integration.go::reportUsageDetailed`; use that path rather than a new reporter/database. Shared `streamio.DoStream` / `ReadSSE` provide the exact transport milestones.

In scope: sampled, fixed-size phase evidence; existing registry/trace integration; secret-safe termination classification; deployment guidance and executable regressions. Out of scope: product error/retry/settlement semantics, new tracing stores or background queues, arbitrary labels or payload capture, transport protocol replacements, real environment configuration, and quota/concurrency implementation from other contributions.

## Functional requirements and implementation
FR1 — Add `internal/observability/request_phases.go`. Read `GATEWAY_REQUEST_DIAGNOSTICS_SAMPLE_EVERY` once when creating the router sampler: absent/0/invalid is disabled; integer 1..1000000 samples exactly one of every N requests using an atomic sequence, with no request-key map. Disabled/unsampled `Start` returns the original context and nil recorder. Sampled requests receive a mutex-protected fixed-size recorder via context; no slices of events, request strings, body/token data, URLs, user/query/nonce/trace identifiers or arbitrary reason fields are accepted. Phase constants: admission wait (duration), upstream start, response headers, first body byte, first content (elapsed offsets from request start). Keep only the first occurrence, clamp numeric values to 0..24h, use -1 for unavailable phases. Terminal reason uses a closed allowlist (completed, rejected, auth_error, forbidden, quota_denied, rate_limited, policy_blocked, header_timeout, idle_timeout, incomplete_stream, buffer_exceeded, client_cancelled, request_timeout, downstream_error, upstream_error, internal_error, other); unknown values collapse to other without logging their input. `Finish` is idempotent and emits at most one fixed-field structured log and one metric observation.

FR2 — Extend the existing `Registry` in `metrics.go` with sampled request-phase histogram (only a constant `phase` label) and terminal counter (only a canonical `reason` label). Do not change existing TTFT/TPS. Register/update the cardinality contract. The sampler HTTP middleware wraps the response with the same existing response-writer facility, applies context/status fallback classification only if no explicit terminal reason exists, and finishes synchronously in defer. No background logger queue or environment mutation.

FR3 — `internal/streamio/http.go::DoStream` marks the initial upstream request and first returned response headers; `sse.go::ReadSSE` captures the optional recorder once, marks first positive-byte read once (using the existing pump completion timestamp), and never records individual tokens. No idle/context/protocol logic changes. Extend `internal/openai/types.go` with a nonallocating semantic-content predicate for text/reasoning/tool deltas (not role/usage-only). `internal/relay/executor.go::Stream` and the direct provider callback in `internal/provider/openai_http.go::Stream` mark first successfully pushed semantic content, with a local first-only guard. Failed push and every retry behavior remain unchanged.

FR4 — At `internal/server/server.go::Router` install the sampler middleware and add only a private diagnostic pointer to `requestIdentity`. `trace_context.go::enrichTraceFromRequest` obtains that pointer from context. `cache_integration.go::reportUsageDetailed` adds a fixed-field `request_phases` snapshot to the existing trace metadata only for sampled calls. `budget_integration.go::runChatQuotaGate` records duration with a minimal defer (stable signature confirmed with the quota contribution owner); set quota_denied on its existing denial paths. Do not touch receipt/lease logic. A new `request_diagnostics.go` classifies only known typed/sentinel errors, never err.Error(), and records final stream terminal reason in the existing main/protocol stream-result block. Do not infer reasons from provider error text or change user-facing errors.
