## 判读

读法：C0 是裸正文（元数据不可见）下各模型各自理解知识，C4 是 OKF 原样呈现（status/stale_after/verified 可见）下的理解。模型 API 温度 0 仍存在采样级非确定性（MoE 类模型），单轮小样本下一致率有 ±1 条查询量级的噪声，读数看趋势与逐条事实，不把百分点当精确量。

本报告为三模型版（glm-5.3-flash、deepseek-v4.1-flash、MiniMax-M3，均彩讯网关+MiniMax 官方，36 次调用）。与两模型版的关键差异：两模型版里 MiniMax 在 C0 把过期知识判为[可直接使用]、C4 被元数据纠正的直接证据，本轮没有复现（MiniMax 本轮 C0 即答对[已过期不可用]）——MoE 模型温度 0 的采样漂移使该证据不稳定，两模型版那条结论降级为"单轮观察，未复现"。

三模型版的逐条事实：纯净/有效查询（物流、退款、库存）三模型两条件全对全一致；分歧集中在陷阱混入的查询，且各模型行为不同——deepseek-v4.1-flash 对配送时效两条件都拒判[信息不足]（元数据可见也如此，拒判型）；订单税率查询三模型一致地以旧税率陷阱为据判[已过期不可用]（一致但都没选有效订单表——一致性不等于正确性）；订单报表查询 glm/deepseek 两条件都以废弃 ETL 为据，MiniMax 在 C4 从[已废弃不可用]翻到[可直接使用]（元数据帮它选对有效片段）。

结论（修正版）：元数据显式化的跨模型收敛效应是条件性的——对愿意读元数据的模型起纠偏作用（MiniMax 订单报表条）；对拒判型模型（deepseek [信息不足]）和自选依据片段的模型不起作用。跨模型一致率指标本身受模型采样噪声影响（两模型 67%→83% 与三模型 83%→67% 方向相反），单轮小样本不能作为元数据价值的依据；逐条事实（谁在什么条件下被纠偏/拒判/选错片段）比汇总百分比更可信。元数据的硬价值仍由离线消融（陷阱 100%→0、token -58%、MRR 随规模拉开）承载，跨模型实验定位为"理解行为观察"而非判定门。

模型 API 异常或标签缺失计入不一致，不剔除。本实验模型调用 36 次（6 查询 × 2 条件 × 3 模型），温度 0；凭证为本机 ~/.agenticx/config.yaml（不入仓库）。DeepSeek v4.1 经彩讯网关接入（deepseek-v4.1-flash）。
