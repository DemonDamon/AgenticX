## 判读

一致率与命中率的对比读法：C0 是裸正文（元数据不可见）下两模型各自理解知识，C4 是 OKF 原样呈现（status/stale_after/verified 可见）下的理解。C0 → C4 跨模型一致率从 67% 升到 83%，双模型均命中期望从 50% 升到 67%——元数据显式化对跨模型收敛有 +16 个百分点量级的贡献。

陷阱查询逐条看"配送时效"：裸正文下 MiniMax-M3 把过期知识判为[可直接使用]（把过期时效口径当有效知识引用，即用户关心的"幻觉式"误用），glm-5.3-flash 判对[已过期不可用]；OKF 呈现下两模型一致收敛到[已过期不可用]。这是元数据消除跨模型误判的直接证据——也是本实验最关键的一条。

诚实记录未被消除的分歧：订单报表查询在两条件下都不一致——glm-5.3-flash 以混入的废弃 ETL 片段为据判[已废弃不可用]，MiniMax-M3 以有效订单表为据判[可直接使用]。多片段混入时两模型各自选择不同的依据片段，这类软分歧属检索排序问题，元数据本身不解决（与消融实验的负发现一致：结构化检索排序需要配合）。

模型 API 异常或标签缺失计入不一致，不剔除。本实验模型调用 24 次（6 查询 × 2 条件 × 2 模型），温度 0 可复算；凭证为本机 ~/.agenticx/config.yaml（不入仓库）。环境说明：DeepSeek v4.1 在本机模型配置中未启用（enabled: false，无 API key），未纳入本实验；智谱官方接口账户余额不足，故 glm 走彩讯网关（glm-5.3-flash）。
