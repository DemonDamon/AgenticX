# Enterprise 对话分享、删除与 Token 展示调整

## 范围

- 在当前会话和消息级分享入口打开选择弹窗，消息级入口默认勾选当前消息，顶部会话入口默认全选当前会话。
- 支持全选/取消全选、创建快照链接、复制链接和生成 PNG；不实现“继续聊天”。
- 分享快照仅保存用户选中的文本、模型和搜索来源，不复制附件二进制、深度研究内部路径等敏感状态。
- 链接由不可猜的随机 token 标识，仅同一企业登录用户可打开；删除源会话时撤销其分享快照。
- 将当前会话头部删除按钮接入现有软删除 API/store。
- web portal 隐藏侧栏用量卡片和会话头部 Token 展示，底层 Token 统计保留。

## 验收

- 数据库 PostgreSQL/MySQL schema 与增量迁移保持一致。
- 选中消息可创建 `/share/<token>` 链接，分享页可复制当前链接并生成/下载图片。
- 删除会话后原分享页不可访问。
- 分享/历史存储定向测试通过；页面启动受本机 PostgreSQL 是否可用影响时，明确记录阻塞原因。
