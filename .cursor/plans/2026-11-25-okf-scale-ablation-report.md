## 规模趋势读数

- A4−A0 Recall 差随规模：15:+0.083 → 60:+0.000 → 200:+0.000 → 600:+0.033（单概念标注下天花板效应明显，Recall 不是规模化的敏感指标）
- A4−A0 MRR 差随规模：15:+0.030 → 60:+0.087 → 200:+0.122 → 600:+0.149——库越大，OKF 结构化检索相对裸 chunk 的首中排名优势越大（600 概念时 A0 MRR 崩塌至 0.382，A4 保持 0.531）。
- 陷阱命中率随规模递降（A1：1.00 → 0.94 → 0.55 → 0.23）：词面打分下大库中陷阱的字面竞争力被稀释；但只要命中，元数据过滤在各规模全部挡住且零召回损失——过滤的防御价值与规模无关，恒定成立。
- token 经济恒定：A4/A0 比各规模均 < 0.5（0.42 → 0.35 → 0.36 → 0.36），上下文成本优势与库容无关。

## 局限

- 打分器仍为词面重叠代理；真实 embedding 下大库陷阱竞争力稀释更弱（语义近邻不受库容稀释），陷阱过滤的价值只会更必要，但幅度需第二期接入向量后端复测。
- 查询标注由生成器自动产生（target 单概念），比人工标注弱；跨规模口径一致，不影响恒定性结论。
- 规模上限 600 概念；更大量级（10k+）受纯 Python 打分器性能限制，第二期换真实向量库时一并扩。
