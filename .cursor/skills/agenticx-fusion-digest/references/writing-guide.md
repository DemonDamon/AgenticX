# 写法与改写对照

## 一句话检验

写完每章后问：只读过所有标题的人，能写出这一章的判断吗？能，就说明这章只是概要，要重写。

## 日报：各部分怎么写

### 标题

用一个判断句做文章标题，不用「AI 日报 11/7」这类栏目名。日期放在副标题或文首一行。

### 开场（1–2 段）

从主线里的张力切入：一个数字、一个反常现象、两篇互相矛盾的结论。不写「本期为大家带来」「今天有几件事值得关注」。

### 主题章节（2–4 个）

章节标题是判断句或问题，比如「专家在环，不等于专家在判断」，不写「Anthropic 动态」。

每章按这个顺序：

1. **判断**：第一句话就说结论。
2. **证据**：来自至少两篇原文。写清实验怎么设计、样本多大、数字多少、和什么比。数字要能在原文找到。
3. **图**：放在它支撑的那段证据后面，图下一句话说明「看哪里」。没有合格的图就不放。
4. **观察**：一到两句，写原文没写的东西。可以是：
   - 推论：这个结论放到读者的场景里会怎样。
   - 边界：结论在什么条件下不成立。
   - 分歧：两篇原文在哪里互相矛盾，你倾向哪边、为什么。
   - 检查项：读者明天就能做的一件事。

观察不能是「这值得关注」「未来可期」「值得我们深思」。

### 收束（3–5 条）

每条比章节再推进一步，可以把两章的结论合起来推出新判断。不复述章节标题。

### 原文索引

每篇一行：`来源 · 标题`，标题带链接。不加摘要。

## 日报篇幅

- 深读 6–10 篇时，正文约 2500–4500 字。
- 深读 3–5 篇时，约 1500–2500 字。
- 单章不超过 1000 字。超过了说明塞了不相干的材料。

## 改写对照

### 条目式（不要）

> **11/4 ·** 用 Claude 调查 vault particles
> 原核细胞中 vault 样蛋白颗粒的首个 3D 结构。重点不只是结果，还有人与 Agent 如何一起找、分离、建模。
>
> **10/27 ·** Agent 如何塑造专家判断
> 随机试验：专业分析师与 coding agent 协作时，86% 会跟着 agent 被随机偏向的选项走。别默认「专家仍握有关键判断」。

问题：每源一段，各说各的；两篇明明在讲同一件事（人和 agent 到底谁在做判断），却没有连起来。

### 融合式（要）

> **专家在环，不等于专家在判断**
>
> 同一周里，Anthropic 发了两篇看起来不相干的研究。一篇是生物学家借助 Claude 解出原核细胞里 vault 样颗粒的首个 3D 结构；另一篇是随机对照实验：研究者让 coding agent 在分析任务里被随机设定偏向某个选项，结果 86% 的专业分析师最终选了 agent 偏向的那个。
>
> 放在一起看，结论比各自单看更尖锐：结构解析那篇成功，是因为每一步「找什么、怎么分离、模型对不对」都由人先提出假设、agent 执行验证；而对照实验里，分析师是在 agent 给出结论之后才介入，判断权在这一刻已经交出去了。
>
> （此处放对照实验的结果图：偏向组与对照组的选择比例。）
>
> 观察：评估人机协作流程时，别只问「有没有人审核」，要问「人在 agent 出结论之前还是之后表态」。一个可以马上做的改动：关键决策节点先让人写下自己的预判，再展示 agent 的建议。

注意上面的数字和细节仅用于示范写法，实际写作必须以原文为准。

## 定向搜集报告

报告是给要做决定的人看的。读者可能只看第一节，所以第一节必须能独立成立。

### 结构

1. **标题**：主题加时间点，例如「企业内部 Agent 平台开源方案选型（截至 2026 年 11 月）」。
2. **结论**（3–6 条）：直接回答 `brief.md` 的主问题。每条一句判断，后面标置信度和引用，例如「多租户和细粒度权限是区分各方案的关键，只有两个项目原生支持（高）[3][7]」。用途是选型时，给出推荐和适用条件。
3. **范围与假设**：查了什么、没查什么、时间范围、采用了哪些默认值、哪些来源没访问成功。
4. **分节回答子问题**：每个子问题一节，节标题写成判断句。先判断，再证据，再观察（这对读者的决定意味着什么）。需要横向比较时用对比表，表格每格写事实，不写「较好」「一般」。
5. **分歧与不确定**：来源之间的矛盾、只有低置信度支撑的说法、变化很快的信息。
6. **没找到的**：查了但没有公开资料的问题，以及建议的补查方式（问厂商、看源码、做测试）。
7. **建议的下一步**：可选。读者接下来可以做的 2–4 件事。
8. **来源**：按 `[n]` 编号列出，每条写等级、发布方、日期、标题和链接。

### 写法要点

- 结论里的每一条，都要能在后面某一节找到展开和证据。
- 引用放在它支撑的那句话后面，不要整段末尾堆一串编号。
- 置信度只有高、中、低三档，定义见 `targeted-research.md` 第 5 步。
- 篇幅随深度：快速约 800–1500 字，标准约 3000–5000 字，深入不设上限，但每节不超过 1500 字，超过就拆。

## 文风

- 写给人看的编辑稿：具体、平实，名词和数字多，形容词少。
- 不用 emoji。不用「速览」「硬核」「重磅」「炸裂」「两边开花」「一文读懂」。
- 不连续用三个以上的排比句，不用「不是……而是……」反复起句。
- 引用原文观点时说明是谁说的；自己的推断写成「我的判断是」或直接陈述，但不要假装是原文结论。
