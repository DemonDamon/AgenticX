# 订阅线程实时事件

> 实时订阅指定线程的完整事件；仅推送连接建立后的新事件。

<Accordion title="使用说明">

live-only；Thread 自己的完整流，primary id 使用 Session 频道。路径不是 /events/stream。

</Accordion>
