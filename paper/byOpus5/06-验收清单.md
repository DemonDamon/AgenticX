## 快速自检脚本

把上述可自动化的部分串成一个脚本，建议落盘 `paper/byOpus5/run_all_ac.sh`，每天开工前跑一次：

```bash
#!/usr/bin/env bash
# 只跑不需要 API key 的离线 AC：0,1.1,3.x,4,5,9,10
set -uo pipefail
FAIL=0
run() { echo "── $1"; shift; if "$@"; then echo "  ✓"; else echo "  ✗ FAIL"; FAIL=1; fi; }
# ...（按上文各 AC 填充）
exit $FAIL
```
