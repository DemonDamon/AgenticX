# TeamBench Phase 1 三模型横评报告

模型: DeepSeek V4 Flash (中档) / DeepSeek V4 Pro (旗舰) / Kimi K3 (推理旗舰,跨厂商)
配置: 15任务 × 2 modes × 2 seeds = 60 runs/模型, 共 180 runs, 90 有效 pairs
Prompt: v3 (single≤4000字, team单角色≤2800字, max_tokens=32768)

## 4. 核心结论 (跨模型稳定成立)

1. **CTR 随耦合度单调递增 (低→中→高)**: 三模型全部成立 ✅✅✅
   - Flash: 0.921 < 0.956 < 0.990
   - Pro:   0.923 < 0.925 < 0.970
   - Kimi:  0.915 < 0.967 < 0.968
2. **低耦合团队次优 (CTR<0.95)**: 三模型全部成立 (0.915/0.923/0.915) ✅✅✅
3. **高耦合接近盈亏平衡但平均不涌现**: 三模型高耦合 CTR 均在 0.96-0.99, 无一超过 1.05 ⚠️
   - 修正原假设3: 团队协作在高耦合下"接近打平", 真正平均涌现仅出现在 PROJ 场景
4. **Project 是唯一团队净赚场景**: Flash 1.044 / Pro 1.032 / Kimi 1.011 ✅✅✅
5. **协调税随模型能力增强而加重**: Flash 2.4x → Pro 3.0x → Kimi 3.4x ✅ (新发现)
   - 更强的模型在团队模式下产出更冗长, 协调开销更大
6. **即使最强模型团队协作平均仍不划算**: 三模型总体 CTR 0.94-0.96, 全部<1 ✅

## 5. 投稿故事线

TeamBench 揭示: (a) 多智能体团队协作存在系统性"协调税"(2.4-3.4x token 开销, 质量不升反降);
(b) 耦合度是团队协作盈亏的分水岭, CTR 随耦合度单调递增且跨 3 模型稳定;
(c) 模型能力提升不能解决协作问题——旗舰模型协调税反而更重;
(d) 唯一例外是项目跟进类任务(信息聚合+冲突消解), 团队分工有真实增益。
