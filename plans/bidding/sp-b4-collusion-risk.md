# SP-B4：围串标风险识别

> 需求映射：需求书 3.1.5 采购风险智能识别（12 需求点 #5）
> 人天：54（后端 10 / 算法 30 / 前端 10 / 测试 4）
> 前置：SP-B1（元数据）、SP-B2（文本抽取）
> 里程碑：M4（W6）三维度风险识别跑通

## 1. 目标

三维度围串标识别（文档属性同源 / 文本特征雷同 / 主体关联），风险分级（高/中/低）预警，每条风险附完整证据链，人工核实闭环。

## 2. 复用盘点

| 能力 | 位置 | 说明 |
|------|------|------|
| embedding/聚类/reranker | `agenticx/embeddings/`、`agenticx/retrieval/` | 文本向量化与相似度底座 |
| 审批原语 | `agenticx/runtime/action_proposals/` | 风险人工核实（核实记录自动归档） |
| 图谱 | 图谱能力以检索策略形态存在（`agenticx/retrieval/base.py` 的 graph 策略）；关联图谱存储经 `deploy/` Neo4j 连通性验证 | 供应商关联关系图谱 |

## 3. 增量设计

### 3.1 三维度识别（`agenticx/bidding/risk/`）

**维度一：文档属性同源（`doc_forensics.py`）**

解析文件底层元数据：PDF 的 Author/Producer/创建时间/修改时间/软件指纹，Office 的编辑设备/用户名/宏代码/修订记录。跨供应商比对：

```python
class DocFingerprint(BaseModel):
    supplier_id: str; file_id: str
    author: str | None; machine_id: str | None
    created_at: datetime; modified_at: datetime
    macro_hash: str | None; producer: str | None
    revision_trail: list[str]

class HomologyFinding(BaseModel):     # 同源发现
    dimension: str; suppliers: tuple[str, str]
    similarity: float; evidence: dict
```

**维度二：文本特征雷同（`text_similarity.py`）**

- 显性：技术方案/商务表述 embedding 相似度（复用底座）
- 隐性：句式结构、错别字模式、段落结构指纹——错别字相同是强信号；实现为 n-gram 指纹 + 编辑距离聚类，不依赖 LLM，可解释

**维度三：主体关联穿透（`entity_graph.py`）**

外部工商数据（企查查/天眼查类，W1 定源、费用归甲方）构建股权交叉、高管重叠、实控人关联图谱，穿透 ≥3 层：

```
供应商A ──持股──> 公司X ──持股──> 公司Y ──持股──> 供应商B   (3层穿透命中)
```

图存储用 Neo4j（deploy 已有连通性验证），穿透查询为固定深度 cypher；数据缺口（工商数据未覆盖）显式标记「穿透不全」而非静默漏报。

### 3.2 风险分级与处置（`agenticx/bidding/risk/scoring.py`）

- 综合三维度信号加权 → 高/中/低三级（阈值在 SP-B5 规则配置页可调）
- 高风险自动推送采购负责人与合规岗（复用 Gateway 通知通道）
- 每条风险附：风险描述、对比数据（指纹对比表/相似度矩阵/关联路径图）、原文位置
- **表述红线**：输出为「风险线索」而非认定结论（法律定性责任边界，见评估表风险清单）
- 人工核实：核实结果（属实/误报/待查）标注 + 归档，走审批原语留痕

### 3.3 前端页面

- 风险预警列表页：分级筛选、证据链查看
- 关联图谱可视化页：供应商关系图（节点=企业/自然人，边=持股/任职，穿透路径高亮）
- 指纹对比详情页：两两供应商元数据对照表

## 5. 验收标准

- 围串标风险识别准确率 ≥90%、误报率 ≤5%（封版评测集）
- 三维度均有独立证据输出；主体关联穿透 ≥3 层
- 高风险自动推送采购负责人与合规岗
- 风险核实记录 100% 留痕归档
- 工商数据缺口导致的穿透不全不视为缺陷（合同已约定数据源责任）

## 6. 依赖与风险

- 依赖：工商数据源（W1 确认，接口费用归甲方）；Neo4j 部署
- 风险：误报率 5% 是紧约束 → 分级阈值在评测集上调参，隐性特征（错别字/句式）权重保守起步；元数据缺失（PDF 清洗过）时降级为文本维度，不虚构同源结论
