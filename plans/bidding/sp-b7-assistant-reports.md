项目总览/横向对比/原文穿透的展示层；解析报告与正式评标报告自动生成（Word/PDF、自定义模板、归档留痕）；评委事实性智能问答；知识库管理 UI（现为空壳）。

## 3. 增量设计

### 3.1 解析结果展示（前端为主，31 人天主体）

- **项目总览**：供应商总数、有效/无效数、风险预警数等核心指标卡
- **供应商横向对比**：资质、报价、业绩、质保期等维度对比表，自定义对比列
- **原文穿透**：任意结构化字段 → 跳转标书原文对应位置并高亮（`enterprise/features/bidding/src/components/SourceViewer/`，基于 PDF.js 定位到页码+区块，对接 SP-B2 的 FieldSource）

### 3.2 评审辅助智能问答（`agenticx/bidding/assistant/`）

- 项目级知识库装配：项目全量投标解析数据 + 采购文件 + 偏离/风险结果进 brain 挂载（`brain/mount.py`），按项目隔离
- 权限过滤：评委提问仅命中其权限范围内数据（联动 SP-B6 的 ReviewerScope）
- **事实性约束**（红线）：prompt + 后处理双重约束——答案仅返回事实性信息与原文出处，不输出倾向性评审意见；回答必附引用位置（原文穿透）
- 交互：复用 chat 工作区，装配 bidding 项目上下文

### 3.3 报告引擎（`agenticx/bidding/reports/`）

- **技术栈**：python-docx + jinja2 模板引擎（Word 生成）→ LibreOffice headless 转 PDF
- **解析报告**（3.1.6）：项目概况、投标单位清单、无效投标说明、核心信息对比表、风险预警清单、客观得分初评表
- **评标报告**（3.2.6）：项目概况、评审委员会组成、评审过程说明、无效投标说明、偏离情况汇总、评分结果与排名、推荐中标候选人、风险提示与建议
- **自定义模板**：模板占位符规范 + 模板管理页上传/预览/绑定采购类型
- **归档**：报告与原始文件、解析数据、操作日志自动关联归档，支持检索与审计；归档后不可篡改，删除需审批留痕（联动 SP-B8 审计扩展）

### 3.4 知识库管理 UI（补建 `enterprise/features/knowledge-base/`）

- 模板管理：采购需求模板、评分标准模板、评标报告模板上传/版本
- 行业知识库：资质标准、参数术语、法规条款条目管理（入库走 Core brain 链路，UI 调 BFF）

## 5. 验收标准

- 原文穿透：结构化字段 → 原文位置高亮，全字段类型覆盖
- 问答仅返回事实性信息 + 原文出处（评测集含诱导性问题样本，如「哪家供应商最好」应拒答倾向性）
- 解析报告/评标报告导出 Word/PDF，格式可直接归档；自定义模板生效
- 报告与原始文件/日志自动关联，归档不可篡改
- 多维度统计报表查询响应 ≤3 秒

## 6. 依赖与风险

- 依赖：SP-B2 FieldSource（穿透定位）、SP-B6 权限范围、SP-B8 BFF
- 风险：LibreOffice 转格式在容器内的字体渲染（中文字体缺失 → 私有化镜像预置 Noto CJK）；问答的事实性约束需红队测试（评委诱导提问样本进评测集）
