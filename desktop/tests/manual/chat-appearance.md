# 聊天外观人工验收

## 运行与准备

功能分支：`codex/desktop-chat-appearance`，独立 worktree 基于本地 `main`。
请从本功能 worktree 启动 Desktop，避免启动原工作区旧代码。进入 `desktop/` 后运行 `npm run dev`；验证正式产物时运行 `npm run build` 后 `npm start`。
新 worktree 不会复制原项目的 Python 虚拟环境；`npm install` 也不会安装 Python 后端。首次运行前，请确认工作区根目录的 `.venv/bin/agx --version` 可执行，且该环境已经具备后端运行依赖。若已有依赖、仅缺少 CLI 入口，可在工作区根目录运行 `.venv/bin/python -m pip install --no-deps -e .`。

后端照常启动，本功能不要求修改后端。设置入口为「设置 → 显示 → 聊天外观」，在强调色设置下方。
准备两个分身 A/B、一个群聊、一张 PNG/JPEG/WebP 图片。以下是待人工执行的用例，并非已通过的真机结果。

## 失败反馈（建议仅使用测试配置环境）

- 模拟写盘失败：应用时显示底层错误，草稿与设置窗口保留，不出现伪成功。
- 在另一进程更改外观 revision 后应用旧草稿：明确提示重新加载；取消旧草稿后可以从最新配置重新编辑。
- 损坏外观配置：应用仍能启动并回退默认外观；设置页给出一次可读提示，不覆盖损坏文件。
- 移走应用管理的某张壁纸资源：仅该壁纸退回静态底色，消息和其他配置可用。测试后恢复文件。

这些失败路径已有自动化覆盖；如人工验证需要修改应用管理的文件，请先备份，并在测试结束后恢复。

## 新背景效果与参数

入口：设置 → 显示 → 聊天外观 → 聊天背景 → 特效背景。

1. 在深色、暗灰、浅色主题下分别选择柔雾噪声、涟漪、玻璃折射、棱纹玻璃、鼠标涟漪；卡片应仅显示对应参数。默认柔和，调整强度/专属参数后预览可见变化。噪声种子和棱纹数量只接受整数。
2. 新选择的效果默认持续缓动；手动改为“发送时变化”后，点击“预览发送效果”可播放约900ms并回到静态背景。切换持续缓动后应持续播放，按钮改为“查看动态预览”；点击任一预览按钮应滚动到上方示例。关闭动效后只显示静态近似，预览按钮禁用。原渐变壁纸保持；特效模式下的动态渐变增加缓慢移动的局部色团。
3. 鼠标涟漪默认持续播放：移入预览或实际聊天区域启用，移出停止；关闭动效后不响应鼠标；动效速度通过消退速率影响鼠标波纹，最高消退速率为20。选字、复制、点消息链接、滚动历史、输入和拖拽附件均正常。
4. 调整背景颜色、气泡颜色、动效速度，再修改效果参数并点击“重置效果参数”：仅参数和混合强度恢复，背景颜色、气泡及播放模式不变。切换效果不改变其他主题变体。
5. 应用前仅示例变化；取消恢复原设置；应用后聊天更新。保存失败时草稿和错误信息保留。不同分身/群聊设置不同效果后，并排展示及重启恢复应保持隔离。
6. 导入此前导出的旧主题：原渐变/图片/气泡可正常预览应用。导出新版主题到本地，再导入另一目标，效果参数一致；取消导入不改变实际聊天。新版主题需本版本应用读取。
7. 设混合强度为0，不应运行可见GPU效果；之后升高强度不应重放很久以前的发送动画。鼠标发送模式下，在区域外发送后再移入不应补放旧动画。
8. 窗口失焦、最小化或系统开启减少动态效果时停止播放；GPU不可用时显示同配色静态近似，参数仍保存。设置预览开启时其他窗格停止GPU背景。
9. 图片壁纸的选择、裁切、缩放、模糊及原有主题预设仍可正常应用；新效果不叠加到图片。

10. 深色噪声可见性回归：背景颜色设为 `#183932 / #2E3D1E / #203E3E / #2B3038`，选择柔雾噪声，保持尺度2、对比度0.15、混合强度0.45、速度1、持续缓动。应用后回到聊天页，在窗口前台观察数秒，应能看到雾状明暗流动；重新打开设置，四个原始颜色和参数保持不变。应用成功后按钮禁用表示没有未保存修改。

11. 效果卡片辨识度：在四个背景颜色相近时，六张卡片仍应分别呈现渐变、雾状色团、同心波纹、玻璃透镜、竖向棱纹和偏心鼠标波纹。卡片为静态示意，实际动态效果在上方示例与聊天页查看。
12. 在相近深色配色下依次选择玻璃折射、棱纹玻璃、鼠标涟漪并应用：应有局部色团与纹理作为折射内容，折射参数调至0与调大时可见区别。鼠标效果移入聊天区并移动指针时才产生波纹，仍能选字、滚动和点击链接。
