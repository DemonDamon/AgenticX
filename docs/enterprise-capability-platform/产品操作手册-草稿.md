## 一、这套能力解决什么

企业要把「平台统一维护的技能 / 专家包」安全地分到各个租户：先登记、再扫描、再发布，然后授权给指定租户；租户侧只读平台下发物、再分配给员工；桌面端 Skills 里能一眼认出「企业官方」。

**企业能力平台（ECP）** 把这条闭环接到现有管理台 / 门户 / Desktop 上（主线 E1–E5 已合入）：

| 你要做的事 | 去哪里 |
|------------|--------|
| 建平台目录草稿（技能包 / 专家包） | 管理台 → 能力包 → **平台目录** |
| 对版本做安全扫描 / 发布上架 | 同一页展开条目 → 版本与上架 |
| 把目录项授权给租户（grant） / 撤销（revoke） | 同一页 → 租户授权 |
| 看租户库里的「平台下发」标识、做二次分配 | 管理台 → 能力包（packs）/ Skill |
| 上架审核（可配） | 管理台 → 能力包 → **上架审核** |
| 桌面认出「企业官方」徽章 | Desktop → 设置 → 技能配置 |

原则：**平台目录是货架；grant 是跨租户分发；租户对平台物只读元数据；revoke 默认停止新下发与后续更新，已同步副本保留。**

本轮已建成（说人话）：

1. **平台目录 + 版本货架**：draft → 扫描 → published。  
2. **跨租户 grant / revoke**：授权进租户库；撤销默认「保留副本、停更新」。  
3. **可插拔上架审核**：可关（只靠扫描门禁），也可开企管 / 平台预设。  
4. **专家包一等公民**：与技能共用货架与分发，不另起平行实体。  
5. **Admin → Portal bootstrap → Desktop**：平台下发物可进分配与桌面同步；Skills 显示「企业官方」。

## 二、怎么登录

1. 确认管理台已启动（开发默认端口 **3001**）；门户演示另需 **3000**；网关常见 **8088**。  
2. 打开 `http://127.0.0.1:3001/login`。  
3. 管理员输入邮箱（本地种子一般为 `admin@agenticx.local`）和本机配置的密码。  
4. 点「登录并进入控制台」。  
5. 进入 Dashboard 后，左侧打开 **能力包**（`/admin/capabilities`）。

**怎么自检：** 首页不是登录页；左侧能看到「能力包」；页内有页签「能力包 / Skill / 平台目录 / 上架审核 / …」。

## 三、打开「平台目录」页签

**谁用：** 平台运营 / 管理员维护跨租户货架。

1. 打开 **能力包**（`/admin/capabilities`）。  
2. 点页签 **平台目录**（URL 变为 `/admin/capabilities?tab=ecp`）。  
3. 应看到卡片标题 **「平台能力目录」**，以及「新建目录草稿」表单。  
4. 下方列表是已有目录条目；空时显示「暂无目录条目」。

**怎么自检：** 页签高亮「平台目录」；不是空白页；文案是中文。

截图：`shots/01-ecp-tab.png`。

![平台目录页签](shots/01-ecp-tab.png)

## 四、新建目录草稿（create）

1. 在「新建目录草稿」填：  
   - **标识（slug）**：例如 `demo-cooling-skill`（演示用，勿绑客户品牌）  
   - **显示名**：例如「冷却巡检技能（演示）」  
   - **资源类型**：技能包 或 专家包  
   - **Bundle 地址**（可选）：指向包产物 URI；专家包还需 JSON 清单  
2. 点创建按钮。  
3. 成功提示「目录草稿已创建」；列表出现新条目，货架状态一般为 **草稿**。

**怎么自检：** 刷新后条目还在；状态是草稿，不是已发布。

截图：`shots/02-create.png`。

![新建目录草稿](shots/02-create.png)

## 五、展开条目 → 扫描（scan）

1. 点列表里某条目录，展开「版本与上架」。  
2. 若还没有版本，先填「新版本号」并「添加版本」。  
3. 在目标版本行点 **扫描**。  
4. 成功后提示「安全扫描已记录」；版本旁出现扫描结论（安全 / 需注意 / 高危）。  
5. **高危** 结论不能靠人工改成「安全」——扫描是自动门禁。

**怎么自检：** 版本行能看到扫描结论；未扫描时显示「未扫描」。

截图：`shots/03-scan.png`。

![版本安全扫描](shots/03-scan.png)

## 六、发布上架（publish）

1. 同一版本行点 **发布**。  
2. 若已开启「目录版本发布」审核预设，未通过审核时会被拦住（提示需先完成上架审核）。  
3. 发布成功后，条目 / 版本货架状态变为 **已发布**。

**怎么自检：** 状态徽章从「草稿」变为「已发布」；已发布版本的扫描/发布按钮会禁用。

截图：`shots/04-publish.png`。

![发布上架](shots/04-publish.png)

## 七、授权给租户（grant）与撤销（revoke）

### 7.1 授权

1. 在展开区找到 **租户授权**。  
2. 填入目标 **租户 ID**（演示用合成 ID，不含真实客户名）。  
3. 点 **授权**。  
4. 成功提示「已授权租户」；列表出现有效授权行。

### 7.2 撤销

1. 在有效授权行点 **撤销**。  
2. 默认策略：**停止后续同步与更新，已下发到桌面的副本保留**（「立即剥离」仅作可选策略，见同页「分发策略」）。  
3. 成功提示「已撤销授权」。

**怎么自检：** grant 后租户库可见平台下发物；revoke 后不再收更新；默认不会悄悄自动恢复历史授权。

截图：`shots/05-grant.png`。

![租户授权](shots/05-grant.png)

同页下方 **分发策略**：默认关闭「安装副本」（纯 grant 引用下发）；开启后才物化租户自有副本。

## 八、租户侧：平台下发标识与二次分配

**谁用：** 租户管理员把平台下发物分给员工 / 能力包成员。

1. 切回页签 **能力包** 或 **Skill**（`/admin/capabilities`）。  
2. 平台下发条目带 **「平台下发」** 标识；元数据只读，不能当租户自建去改平台字段。  
3. 仍可做可见范围 / 二次分配（加入能力包成员、给桌面 bootstrap）。  
4. 门户登录后，员工侧按企业分配策略看到可用能力（bootstrap / 注入）；具体菜单以租户配置为准。

**怎么自检：** 平台物有「平台下发」徽章；改元数据应失败或控件不可用；分配后 Desktop / 门户能拿到。

门户工作区示意：`shots/07-portal-workspace.png`。

![门户工作区](shots/07-portal-workspace.png)

## 九、Desktop Skills：「企业官方」徽章

**谁用：** 一线同事在桌面端确认技能来源。

1. 打开 Desktop（Near）→ **设置** → **技能配置**。  
2. 在全局 / 自建技能列表中，平台下发并同步到本机的技能会显示 **「企业官方」** 徽章。  
3. 技能市场筛选里也可点「企业官方」只看企业下发物。

**怎么自检：** 搜索或刷新后，目标技能旁有「企业官方」；不是空白第三方列表。

## 十、上架审核（可选）

1. 打开页签 **上架审核**（`/admin/capabilities?tab=approvals`）。  
2. 可为「Skill 上架 / 引入平台物 / 目录版本发布」选择审核预设；关闭则仅保留安全扫描门禁。  
3. **待办审核** 队列可对申请单 **通过 / 驳回**（驳回必填原因）。  
4. 未完成审核时，发布会被拦住。

**怎么自检：** 关预设时扫完即可发；开预设时未审不能发；驳回有原因可追溯。
