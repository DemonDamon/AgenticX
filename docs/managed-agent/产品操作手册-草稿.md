## 一、这套能力解决什么

企业要把「可复用的智能体定义」统一登记、按版本发布，再安全地跑起来：模型走网关、凭证不进明文、会话可观测、用量可计量。同一个定义既可以跑在企业自托管的云端运行时，也可以挂到员工桌面——事件、审批、记忆都回到同一套控制面。

**托管智能体（Managed Agent）** 把这条闭环接到现有管理台 / 门户 / agent-runtime 上：

| 你要做的事 | 去哪里 |
|------------|--------|
| 启用可用模型 | 管理台 → 平台 → **模型** |
| 定「在哪跑」 | 资源配置 → **执行环境** |
| 登记密钥（MCP / 环境变量等） | 资源配置 → **凭证库** |
| （可选）跨会话记忆 | 资源配置 → **记忆库** |
| 建智能体并发布 | 智能体运行 → **智能体** |
| 在门户验跑 | 门户 → **协作房间** |
| 看跑得怎样 / 花了多少 | **会话**、**智能体用量** |
| （可选）定时 / 外推 / 飞书 / 评测 | 定时任务、Webhook、IM 渠道、评测 |

原则：**先资源后定义；先发布后验跑；密钥只进凭证库，不进手册和旁白。**

本轮已建成（说人话）：

1. **智能体定义 + 版本发布**：模型、提示词、能力、可见范围一次配齐。  
2. **执行环境 / 凭证库 / 记忆库**：管「在哪跑、用什么密钥、记什么」。  
3. **会话观测 + 用量 / 配额**：跑完能回头看，配额可按「用户 × 智能体」卡。  
4. **定时任务 / Webhook / IM 渠道**：到点触发、签名通知、飞书长连接（均有运行时开关）。  
5. **评测（可关）**：评测集 → 评分标准 → 任务 → 候选版本；候选不自动顶替线上。

## 二、登录与服务自检

1. 确认四件套已起（本地开发默认端口）：  
   - Admin **:3001** · Portal **:3000** · Gateway **:8088** · agent-runtime **:8092**  
2. 打开 `http://127.0.0.1:3001/login`。  
3. 管理员输入邮箱（本地种子一般为 `admin@agenticx.local`）和本机配置的密码。  
4. 点「登录并进入控制台」。  
5. 进入 Dashboard 后，左侧应看到两组：**智能体运行**、**资源配置**。顶栏 / 底栏 Gateway 徽章宜为 healthy / online。

**怎么自检：** 首页不是登录页；侧栏两组齐全；Gateway 非持续 offline；需要时再 curl Gateway / agent-runtime 的 `/healthz`。

关键开关（部署侧配置，手册只写含义）：

| 变量 | 作用（摘要） |
|------|----------------|
| `MA_RUNTIME_ENABLED=1` | 门户协作房间云端智能体改由 agent-runtime 执行 |
| `NEXT_PUBLIC_MA_EVALS_UI_ENABLED=1` | 侧栏是否显示「评测」 |
| `MA_RUNTIME_EVALS_ENABLED=1` | 运行时是否真正跑评测 |
| `MA_RUNTIME_SCHEDULER_ENABLED=1` | 定时任务 tick |
| `MA_RUNTIME_WEBHOOKS_ENABLED=1` | Webhook 入队与投递 |
| `MA_RUNTIME_CHANNELS_ENABLED=1` | 飞书长连接（持锁副本） |
| `MA_RUNTIME_AGENT_QUOTA_ENABLED=1` | 执行侧拦截「用户 × 智能体」配额 |

## 四、推荐落地顺序

```text
① 服务自检（Admin / Portal / Gateway / agent-runtime）
        ↓
② 模型：至少启用一个
        ↓
③ 执行环境
        ↓
④ 凭证库（密钥进详情，勿外泄）
        ↓
⑤ （可选）记忆库
        ↓
⑥ 建智能体 → 发布
        ↓
⑦ Portal 协作房间验跑（需 MA_RUNTIME_ENABLED=1）
        ↓
⑧ Sessions 观测 · Usage / 配额回头看
```

可选支线：定时任务 / Webhook / IM 渠道；评测路径 Datasets → Rubrics → Runs → Candidates → 回智能体页切版本。

## 五、逐页操作

### 5.1 智能体 · `/admin/agents`

**谁用：** 管理员登记可在协作房间等场景使用的托管智能体。

1. 打开 **智能体运行 → 智能体**。  
2. 点 **新建智能体**。  
3. 填名称、标识（slug）、描述；选已启用 **模型**；运行方式默认云端；写系统提示词；按需绑 MCP / Skill；设可见范围与启用。  
4. 保存后，在列表做编辑、**发布 / 回收**、看定义与版本。

**怎么自检：** 无启用模型时对话框会提示「还没有已启用的模型」；发布后命中可见范围的成员可在房间使用。

截图：`shots/03-agents.png`、`shots/03b-agents-new-dialog.png`。

![智能体列表](shots/03-agents.png)

![新建智能体](shots/03b-agents-new-dialog.png)

### 5.2 会话 · `/ops/logs/managed`

1. 打开 **会话**。若首屏短暂空白，点 **刷新**。  
2. 按智能体、请求邮箱、状态、来源、时间范围筛选。  
3. 空状态：**暂无托管会话**。

截图：`shots/04-logs-managed.png`。

![托管会话](shots/04-logs-managed.png)

### 5.3 定时任务 · `/admin/agent-schedules`

需 `MA_RUNTIME_SCHEDULER_ENABLED=1`。

1. **新建定时任务**：选智能体、版本策略、执行环境；Cron 示例 `0 9 * * 1-5`；时区 `Asia/Shanghai`；填输入内容（可用 `{{date}}` 等占位符）。  
2. 行内可编辑、立即运行、看运行记录、删除（历史保留）。

截图：`shots/06-agent-schedules.png`、`shots/06b-schedule-dialog.png`。

![定时任务](shots/06-agent-schedules.png)

### 5.4 智能体用量 · `/metering/agents`

1. **Usage**：选起止时间，勾选分组（智能体 / 用户 / 部门 / 模型 / 天），点查询。  
2. **Quotas**：选智能体后看「用户 × 智能体」配额；执行侧拦截另需 `MA_RUNTIME_AGENT_QUOTA_ENABLED=1`。

截图：`shots/07-metering-agents.png`、`shots/07c-metering-quotas.png`。

![智能体用量](shots/07-metering-agents.png)

### 5.5 执行环境 · `/admin/agent-environments`

1. **新建环境**：名称、类型（云端 / 员工桌面）、沙箱后端、镜像、出站白名单、空闲回收秒数。  
2. 停用后新会话不可再选；进行中会话不受影响。

截图：`shots/08-agent-environments.png`、`shots/08b-environment-dialog.png`。

![执行环境](shots/08-agent-environments.png)

![新建执行环境](shots/08b-environment-dialog.png)

### 5.6 凭证库 · `/admin/agent-vaults`

1. **新建凭证库**（名称 + 描述即可）。  
2. 进详情再 **新增凭证**（MCP 令牌、OAuth、Bearer、环境变量等）。  
3. 会话引用后由运行时注入，**智能体看不到原文**。主密钥由部署侧文件保管。

截图：`shots/09-agent-vaults.png`、`shots/09b-vault-dialog.png`。

![凭证库](shots/09-agent-vaults.png)

### 5.7 记忆库 · `/admin/agent-memory`

可选。新建名称 / 描述；共享知识优先只读挂载。首屏短暂空白可稍候或刷新。

截图：`shots/10-agent-memory.png`、`shots/10b-memory-dialog.png`。

![记忆库](shots/10-agent-memory.png)

### 5.8 Webhook · `/admin/agent-webhooks`

需 `MA_RUNTIME_WEBHOOKS_ENABLED=1`。新建端点 URL、事件类型（约 29 类）、高级过滤。创建后签名密钥通常只展示一次——**勿写入文档或截图**。

截图：`shots/11-agent-webhooks.png`、`shots/11b-webhook-dialog.png`。

![Webhook](shots/11-agent-webhooks.png)

### 5.9 IM 渠道 · `/admin/agent-channels`

需 `MA_RUNTIME_CHANNELS_ENABLED=1`。绑定飞书自建应用与智能体；App Secret 进单独凭证库，**勿写入手册**。

截图：`shots/12-agent-channels.png`、`shots/12b-channel-dialog.png`。

![IM 渠道](shots/12-agent-channels.png)

### 5.10 评测 · `/admin/agent-evals`（开关）

显示条件：`NEXT_PUBLIC_MA_EVALS_UI_ENABLED=1`；真正跑评测还需 `MA_RUNTIME_EVALS_ENABLED=1`。

四个页签：**评测集 → 评分标准 → 评测任务 → 候选版本**。候选产生后**当前生效版本不变**，需回智能体页手动切换。

截图：`shots/05-agent-evals.png`、`shots/05b-evals-dialog.png`。

![评测](shots/05-agent-evals.png)

## 六、Portal：工作区与协作房间

配置在管理台；终端用户主要在门户用。

| 入口 | 说明 |
|------|------|
| `/workspace` | 工作区：新对话、深度研究、**协作房间**、我的项目、用量与模型选择 |
| `/rooms` | 协作房间：新建房间并邀请同事 |

当 `MA_RUNTIME_ENABLED=1` 且已登记云端智能体、模型可用时，房间内云端智能体由 agent-runtime 执行。工作区侧栏未必出现名为「Managed Agent」的独立入口。

## 七、常见问题

| 现象 | 建议处理 |
|------|----------|
| 新建智能体提示没有已启用模型；门户「No models available」 | 先在平台 **模型** 启用。**无模型跑不通** |
| 侧栏没有「评测」 | 查 `NEXT_PUBLIC_MA_EVALS_UI_ENABLED=1` 并重建管理台前端 |
| 定时任务到点不触发 | `MA_RUNTIME_SCHEDULER_ENABLED=1`、任务启用、cron/时区、runtime 健康 |
| Webhook 无投递 | `MA_RUNTIME_WEBHOOKS_ENABLED=1`、端点可达 |
| 飞书机器人不回复 | `MA_RUNTIME_CHANNELS_ENABLED=1`、App/Vault、连接状态「已连接」 |
| Gateway 徽章红绿抖动 | 短时可刷新；持续 offline 查进程与内部 token |
| Sessions / Memory 首屏短暂空白 | 等数秒或 Refresh |
| 配额页有数但不拦截 | 执行侧需 `MA_RUNTIME_AGENT_QUOTA_ENABLED=1` |
