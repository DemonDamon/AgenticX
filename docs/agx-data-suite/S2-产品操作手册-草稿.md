## 二、启动与登录

### 步骤

1. 确认管理台已启动（开发默认端口 **3001**）。
2. 浏览器打开登录页：`http://127.0.0.1:3001/login`。
3. 输入管理员邮箱（本地种子一般为 `admin@agenticx.local`）和本机配置的管理员密码。
4. 点击「登录并进入控制台」。
5. 登录成功后应进入 Dashboard。

### 预期

- 能看到控制台首页，左侧导航含「数据治理」「数据看板」等入口。

（登录页与 Dashboard 可参考仓库历史截图 `docs/agx-data-suite/shots/01-admin-login.png`、`02-admin-dashboard.png`。）

## 三、数据看板

### 3.1 打开看板

1. 左侧导航点击 **数据看板**（路径 `/admin/data-boards`）。
2. 等待标题从「正在加载…」变为样例标题（含 **Member overview**）。
3. 页面应出现多个图表卡片（地区分布、层级分布、统计指标等）。

### 3.2 下钻

1. 在下钻选项区域点击维度值 **A**。
2. 查看「当前下钻路径」是否包含 **A**。
3. 图表随过滤条件更新。

### 3.3 打开对比

1. 点击 **对比** 按钮。
2. 按钮文案变为「对比：开」或 “Compare: on”。
3. 柱状/折线图出现 A/B 两套系列。

### 验收标准

根视图、下钻、对比三种状态均可截图复现，标题与组件不是空白页。

## 四、数据治理（字典可写）

### 4.1 打开治理页

1. 左侧导航点击 **数据治理**（`/admin/data-governance`）。
2. 表格列出字段名、负责人、更新频率、业务定义。
3. 不应长期停在「仅 stub、无法加载」状态（API 正常时 stub 提示不出现）。

### 4.2 新增字段并验证持久化

1. 在表单中填写示例字段，例如：
   - 字段名：`e2e_field_demo`
   - 负责人：`data-platform`
   - 更新频率：`daily`
   - 业务定义：任意简短说明
2. 点击保存/提交。
3. **刷新浏览器**（硬刷新）。
4. 在表格中再次找到 `e2e_field_demo`。

### 验收标准

刷新后字段仍在 → 说明已写入文件仓，而不是仅内存展示。

## 五、数据安全

1. 打开 **数据安全**（`/admin/data-security`）。
2. 确认样例手机号为脱敏形态（例如中间位为 `*`，如 `1*********8`）。
3. 确认页面带有水印层（页面上可见水印或 DOM 中存在 watermark）。

### 验收标准

脱敏串正确、水印存在，截图可复核。

## 六、命令行黄金路径（引擎侧）

在仓库根目录执行：

```bash
pytest tests/data_suite/ tests/managed/templates/ -q --override-ini='addopts='
```

## 七、通道能力对照（实施）

| 配置 kind | 行为摘要 |
|-----------|----------|
| fake | 内存表，离线演示/CI |
| clickhouse | 可选真驱动 |
| jdbc / sql / postgres / mysql / sqlite | 有 url 或 host → 真 JDBC 通道；仅 tables → Fake |
| kafka | 有 bootstrap → Kafka 通道；仅 tables → Fake；单测用内存 transport |
