## 一、这套能力解决什么

企业里数据散在多处：字段口径对不上、取数越权、作业跑了没人盯、同一人多个 ID 对不上、定时巡检靠人肉。

**Data Suite** 把这些接到管理台里，让管理员和分析师能直接操作：

| 你要做的事 | 去哪里 |
|------------|--------|
| 管字段字典、清洗、分级、质量、审核 | 数据治理 |
| 看看板、下钻、对比 | 数据看板 |
| 脱敏预览、按权限自助取数 | 数据安全 / 自助取数 |
| 调度作业、看历史、重跑 | 数据作业 |
| 配 ID 类型、处理冲突 | ID 映射 |
| 按 cron 拉起智能体会话 | 定时任务 |
| 用自然语言问数（只读） | 自然语言取数 |

原则：**默认只读；写操作要授权；展示默认脱敏。**

## 二、怎么登录

1. 确认管理台已启动（开发默认端口 **3001**）。
2. 打开 `http://127.0.0.1:3001/login`。
3. 管理员输入邮箱（本地种子一般为 `admin@agenticx.local`）和本机配置的密码。
4. 点「登录并进入控制台」。
5. 进入 Dashboard 后，左侧应能看到「数据治理」「数据看板」「数据作业」「ID 映射」「定时任务」等入口。

**怎么自检：** 首页不是登录页；左侧导航是中文。

## 三、数据看板

**谁用：** 分析师 / 业务同学看概览。

1. 左侧点 **数据看板**（`/admin/data-boards`）。
2. 等标题从「正在加载…」变成样例标题（如 Member overview）。
3. 页面会出现地区分布、层级分布等图表卡片。
4. **下钻：** 在下钻选项点维度值 **A**，「当前下钻路径」应带上 A，图表随之过滤。
5. **对比：** 点 **对比**，文案变成「对比：开」，图上出现 A/B 两套系列。

**怎么自检：** 根视图、下钻、对比三种状态都能截到；不是空白页。

截图：`a6-data-boards-root.png` / `a6-data-boards-drill-A.png` / `a6-data-boards-compare.png`。

## 四、数据治理

**谁用：** 管理员维护字段口径与治理规则。

### 4.1 打开字典

1. 左侧点 **数据治理**（`/admin/data-governance`）。
2. 表格应列出字段名、负责人、更新频率、业务定义。
3. 正常情况下不应长期停在「仅 stub、无法加载」。

### 4.2 新增字段

1. 在表单填示例，例如：
   - 字段名：`demo_pump_temp`（示例化工厂·泵温）
   - 负责人：`data-platform`
   - 更新频率：`daily`
   - 业务定义：一句话说明即可
2. 保存。
3. **硬刷新**浏览器，再在表格里找到同一字段——说明写进库了，不是页面假数据。

### 4.3 清洗 / 分级 / 质量 / 审核

在同一页切页签：

1. **清洗：** 新增一条清洗规则并保存，列表里能看见。
2. **分级：** 新增等级并保存。
3. **质量：** 新增质量指标 → 点运行 → 看最近一次结果。
4. **审核：** 对目标规则做通过/驳回，列表可回看。

**怎么自检：** 刷新后字段还在；四个页签都能增改；质量能跑出一轮结果。

截图：`s2-data-governance-list.png`、`h3-data-governance-ops.png`。

## 五、数据安全与自助取数

**谁用：** 管理员看脱敏与水印；分析师按权限取数。

### 5.1 数据安全

1. 打开 **数据安全**（`/admin/data-security`）。
2. 样例手机号应是中间打 `*` 的脱敏形态。
3. 页面应有水印层。

### 5.2 自助取数

1. 打开取数相关入口（常见为 `/admin/data-query`，或安全页内的「自助取数试探」面板）。
2. 取数会走权限校验和脱敏：越权应失败，或只能看到脱敏结果。
3. 产品口径：**默认只读；写操作需授权；展示默认脱敏。**

**怎么自检：** 脱敏样例可见；无权限请求被拦住或结果被遮住。

截图：`a7-data-security.png`、`h5-data-query-acl.png`。

## 六、数据作业

**谁用：** 管理员盯调度与重跑。

1. 左侧打开 **数据作业**（`/admin/data-jobs`）。
2. 应能看到样例作业（如 `golden_path_members`）。
3. 触发调度或重跑后，运行历史出现对应记录（schedule / manual，状态 succeeded）。

**怎么自检：** 作业列表非空；点一次调度/重跑后历史多一条成功记录。

截图：`h6-data-jobs.png`。

## 七、ID 映射

**谁用：** 管理员配假 ID 类型、看冲突。

1. 打开 **ID 映射**（`/admin/data-idmapping`）。
2. 能看到样例 profile（如手机号 + 邮箱一类假 ID）。
3. 冲突审阅表可加载；需要时人工裁决合并。

产品口径：演示用假 ID，不绑定客户真实业务 ID 体系。

**怎么自检：** 页面能打开；profile 与冲突表至少有一块有内容。

截图：`h7-data-idmapping.png`。

## 八、定时任务

**谁用：** 管理员按 cron 给智能体开独立会话。

1. 左侧 **智能体运行** → **定时任务**（`/admin/agent-schedules`）。
2. 面包屑：`管理后台 > 智能体运行 > 定时任务`。
3. 标题是中文 **「定时任务」**；右上角有 **「新建定时任务」**。
4. 无任务时为空态「还没有定时任务」。
5. 新建后可按 cron / 时区启用；到点或手动「运行」会开新会话并留下运行记录。

**怎么自检：** 导航和标题都是「定时任务」；能点到新建。

截图：`h9-agent-schedules.png`。

## 九、自然语言取数（只读）

分析师可以用自然语言提问，系统会生成**只读查询**并返回结果。

- 问「示例化工厂里 1号泵最近温度」这类问题 → 生成 SELECT 类查询并执行。
- 若模型给出 INSERT / DROP 等写操作 → **会被拦住**，不会落到数据通道。
- 已用真实模型做过抽检；日常演示不必每次调外部大模型。

管理台「定时任务」负责把这类问数/巡检按计划拉起来；具体行业话术包按项目配置，不在本手册展开。

**怎么自检：** 只读提问有结果；故意写操作被拒。

## 十、通道与场景对照（人话）

实施时按配置选择数据通道，不必记内部编号：

| 你要接什么 | 怎么理解 |
|------------|----------|
| 离线演示 / CI | 内存假表，不连外库 |
| ClickHouse / JDBC（Postgres、MySQL 等） | 配好 url/host 就走真库；只配表结构时用假表 |
| Kafka | 有 bootstrap 走真消息；否则假表 |
| 文件清单 | 按路径策略扫文件，默认只读 |
| Hive / Spark Thrift | 连 HiveServer2 一类探查 |

看板、治理、取数、作业、ID 映射、定时任务都挂在管理台；自然语言取数挂在只读通道上。圈选下推、巡检计量等进阶能力按项目打开即可。
