# 安全问数 W4 — 手动点击步骤

入口：`/admin/data-nl2sql`（侧栏「安全问数」）

## 讲解 → 执行

1. 打开管理端，进入 **安全问数**。
2. 默认问句：`上月华东大区 GMV 和退货率分别是多少？`
3. 模式选 **讲解** → **运行**：应看到 SQL 草案，提示「通道未执行」，无结果行。
4. 切换 **执行** → **运行**：应看到结果表（含 `华东` / GMV / 退货率样例）。

## 写闸拒绝

1. 点击 **填入写闸演示**（会切到执行并填入 `DELETE …`）。
2. **运行**：红色「写闸拒绝」区域显示「写闸已拒绝：SQL 非只读，未执行」，错误码 `write_guard_denied`。

## 发布后邻域

1. **知识生命周期**：将对象审阅并发布为 `published`。
2. 详情区出现 **查看邻域** → 跳转 `/admin/graph-explorer?focus=<对象ID>`。
3. 图谱详情侧栏展示邻域节点列表。
