## 商店名称

AGX Bridge — AgenticX 浏览器代理

## 一句话简介（132 字符内）

把浏览器接入 AgenticX 桌面端：划词/整页发送给 AGX 会话，并让 AGX 在你的浏览器里打开页面、提取内容、填表与截图。

## 详细描述

AGX Bridge 是 AgenticX（AGX）桌面端的浏览器伴侣扩展。安装后，你可以：

- **划词发给 AGX**：在任何网页选中文字，右键即可发送给当前活跃的 AGX 会话，作为上下文继续对话或执行任务；
- **整页发给 AGX**：把当前页面的标题、正文与选中内容发给 AGX 会话；
- **让 AGX 操作浏览器**：在 AGX 中下达指令，由扩展在**你的浏览器**里完成打开链接、提取页面内容、填写/点击表单、截取当前页面等操作——全程你可见、可打断。

**安全设计**

- 扩展只与**本机的 AGX 桌面端**通信（Native Messaging + 本机 Unix 套接字），不连接任何第三方服务器；
- 内置银行/证券等敏感站点拦截清单，默认拒绝在这些页面上执行任何自动化操作，且须经你在扩展选项页逐站确认；
- 所有页面注入、截图等能力均按站点/按功能**显式授权**，可随时在选项页回收；
- 数据全部本地处理、不上传第三方。

使用本扩展需要安装并运行 AGX 桌面端。

## 权限用途逐条说明（后台「权限理由」栏逐条粘贴）

| manifest 权限 | 用途说明 |
| --- | --- |
| `activeTab` | 你点击扩展图标或右键菜单（划词/整页发送）时，读取当前标签页的标题、URL 与选中内容，并注入提取脚本。授权只在当次操作生效，不常驻。 |
| `scripting` | 「发给 AGX」时向当前页面注入只读的文本提取脚本；以及 AGX 执行页面提取/表单填写时按站点授权注入。 |
| `contextMenus` | 注册「划词发给 AGX / 整页发给 AGX」右键菜单项。 |
| `storage` | 在本机保存扩展设置：已授权域名清单、桌面端网关地址、连接状态。 |
| `notifications` | 页面注入/敏感站点拦截等事件发生时弹出本地通知提示。 |
| `tabs` | 维护与本机 AGX 桌面端的标签页状态同步（打开/关闭/切换），供其执行打开页面等操作。 |
| `nativeMessaging` | 与本机 AGX 桌面端建立 Native Messaging 通道——这是扩展与桌面端通信的唯一途径，全部流量发生在本机。 |
| `alarms` | 心跳保活（桌面端连接状态检测），无定时上报行为。 |
| `optional_host_permissions: <all_urls>` | **可选**权限，仅在你在选项页主动开启「浏览器截图」时申请，用于 AGX 执行截图操作；可随时在选项页关闭。默认不开启，扩展不持有任何常驻站点权限。 |

## 隐私声明（隐私惯例表）

- **不收集**任何个人身份信息、浏览历史、表单数据；
- **不上传**任何数据到开发者或第三方服务器：扩展与 AGX 桌面端之间通过本机进程间通道（Native Messaging + Unix domain socket）通信，你发送的页面内容仅进入你本机的 AGX 会话；
- 不使用分析/统计/广告 SDK；
- 权限按需最小化：无常驻 `<all_urls>` 站点权限，页面注入按站点单独授权，浏览器截图为可选权限且默认关闭。

**单用途说明**：本扩展的唯一用途是把浏览器内容/操作能力桥接给本机 AgenticX 桌面端。

## 商店路径与 NM host 注册的注意事项

上架商店后 Chrome Web Store 会重新签名分配**正式扩展 ID**，与本仓库固定的开发 ID
（`kajgkmohjdflaidencpfmebbjibfieka`，由 manifest `key` 锁定）不同。NM host 注册
（`allowed_origins`）必须包含正式 ID，发布流程：

1. 上架通过后从 dashboard 记录正式 ID；
2. `installNmHost({ extensionId: "<正式ID>" })`（desktop/electron/native-messaging-host.ts，随桌面端发版）；
3. 桌面端启动时幂等覆盖注册，用户无需手动配置。

在企业路径（自签 CRX）中 ID 与本仓库 key 一致，无需该步骤。
